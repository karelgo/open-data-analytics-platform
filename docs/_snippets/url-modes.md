!!! info "URLs in deze handleiding"
    De URLs hieronder gebruiken het **k3d-laptop-domein** (`*.odap.local:8443`).
    Op andere modes:

    - **aks** (Azure): vervang `*.odap.local:8443` door `*.example.com` (poort 443, dus geen `:8443`).
    - **stackit** (SKE): vervang door `*.example.com` (poort 443).

    Zie [Deployment modes](../deployment-modes.md) voor de complete matrix.
