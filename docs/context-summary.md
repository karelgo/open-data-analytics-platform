# Scope of the reference

The platform demonstrates one technical data journey: daily Dutch IT job advertisements across Data, Cloud, SAP, AI, Software and Security. It combines reproducible synthetic fixtures with an explicitly selected live extraction path.

The dataset describes vacancies and their source evidence. It does not contain CVs, candidate assessments, applicant rankings or recruitment decisions. Public descriptions can still include recruiter contact details; raw evidence stays restricted and analytical descriptions redact email/phone details.

Access controls, provenance and data-quality tests are implementation examples. Their presence is not a certification or a statement that all regulatory requirements have been satisfied. Operators remain responsible for source access, reuse terms and environment configuration.
