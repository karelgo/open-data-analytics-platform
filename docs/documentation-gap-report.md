# Validation and remaining limits

The job-market example has an offline verification path and a platform execution path. Passing local tests does not establish that source credentials, external APIs, Kubernetes services or a deployed Airflow scheduler are working in a particular environment.

- Live source access must be configured and verified with the provider.
- Search results are bounded observations rather than a census of all Dutch vacancies.
- Source descriptions may be abbreviated and many fields may be unknown.
- Deduplication is conservative and can produce missed or false matches.
- Salary samples are not a representative wage survey or normalized full-time-equivalent compensation.
- Catalog/dashboard publication depends on services being reachable in the deployment.
