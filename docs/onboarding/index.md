# Start with Dutch IT Job Market

One use case follows daily Dutch IT vacancy observations from extraction to analysis across Data, Cloud, SAP, AI, Software and Security.

1. Run `make jobs-demo` and `make jobs-test` from a checkout with Python 3.11+.
2. Open `/job-market/` in the portal and filter the clearly labelled synthetic observations.
3. Read the [walkthrough and dictionary](../use-cases/dutch-it-job-market.md).
4. On an installed platform, run `make jobs-image` and `make jobs-run`.
5. Trace the same `job_market` tables in Airflow, MinIO, Trino, dbt, Superset, Jupyter and OpenMetadata.
