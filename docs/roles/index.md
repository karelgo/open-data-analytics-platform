# Roles on the job-market dataset

All role perspectives work on the same Dutch IT vacancy subject. Existing identity keys remain for compatibility with platform accounts.

Analyst perspectives read Gold job-market tables. Approved researchers can read contact-redacted Silver and Gold observations. Data engineers and stewards have additional pipeline and quality scopes; platform admins operate infrastructure and identity.

[Open the role handbooks](../handbooks/README.md). The authority for permissions is the OPA source configuration, not this overview.
